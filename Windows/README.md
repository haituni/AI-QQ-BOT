# 栖 · Windows 版

> GitHub 仓库已附带 Windows x64 桌面启动器 `栖.exe`。目录不包含 Python、项目依赖、模型、下载缓存或运行数据；首次启动时再自动准备所需组件。

栖是运行在自己电脑上的 QQ AI 伙伴。它通过 NapCat 接入独立的机器人 QQ 账号，使用 DeepSeek 理解消息、决定是否回复，并提供浏览器管理界面，用来管理账号、角色、会话授权、记忆和运行状态。

适合希望在 QQ 私聊或群聊中使用可自定义角色、持续记忆和主动联系功能的用户。模型调用需要自行配置 DeepSeek API Key，并产生相应费用。

## 项目功能

- **QQ 聊天**：处理已授权好友和群聊的消息，支持文字、按需识图、消息合并、回复等待与分条发送。
- **角色工坊**：管理角色卡、用户人设、关键词世界书和生成预设，支持 JSON / PNG 角色卡导入导出及独立试聊。
- **记忆与情绪**：按会话保存近期消息、长期原文和压缩记忆，并按角色与 QQ 维护情绪状态，影响表达和回复节奏。
- **主动联系**：为授权会话设置时间范围、间隔和每日上限，由模型判断是否发起聊天。
- **模型工具与自主生活**：按设置使用识图、表情收藏、QQ 互动及空间表达等功能，受工具开关、会话权限和额度约束。
- **本机管理**：在网页中完成配置、扫码登录、连接检查、环境任务、运行记录、备份与恢复。

## 初始角色与数据

本版本包含「栖」「灯下的旅人」「大肥鱼」及关联世界书和生成预设，保存在 `initial/roleplay.json`。首次启动会自动载入，默认选择「栖」；可以在角色工坊切换角色。用户人设是空白的「我」，可自行填写。

这是不含原使用者私人数据的独立版本：不携带账号、API 密钥、QQ 登录状态、授权会话、聊天记录、记忆、情绪状态、日志或备份。首次运行会生成当前安装自己的配置和密钥。

初始角色只在本地设置尚不存在时加载，后续启动保留用户修改；编辑初始文件不会覆盖已经保存的角色设置。

## Windows 桌面启动

日常双击仓库附带的 **栖.exe**，首次会显示安装窗口，自动准备项目内 Python、依赖和表情模型；无需预装 Python，也不会弹出命令窗口。安装中断后，可在窗口中重试。完成后自动打开浏览器控制台。

程序常驻系统托盘，支持打开控制台、查看启动进度、查看日志、停止机器人并退出。重复双击应用会唤回已有启动器。关闭进度窗口只会隐藏窗口，退出请使用托盘菜单。

本版本面向 **Windows x64 / .NET Framework 4.8**。QQ 接入仍需先安装并启动 Docker Desktop，使用 WSL 2 后端和 Linux 容器模式，见 [Docker 官方安装说明](https://docs.docker.com/desktop/setup/install/windows-install/)。Python 和 Docker 的安装是两个不同步骤，启动器不会自动启用系统虚拟化或安装 Docker Desktop。

1. 从仓库下载 ZIP 并解压，或将完整发行文件夹放在可写的本地目录，避免路径中含逗号；`栖.exe` 与 `scripts/` 保持同级。
2. 双击 **栖.exe**，等待图形安装完成并打开控制台。
3. 在「账号与连接」填写管理 QQ、独立的机器人 QQ 和 DeepSeek API Key，保存并测试连接。
4. 点击「打开 QQ 扫码登录」，在网页查看 Docker / NapCat 准备进度，再使用手机 QQ 扫码确认。
5. 在角色工坊选择角色，并授权需要处理的好友或群聊。

QQ 容器数据位于 `runtime/napcat/`；镜像和 Docker Desktop 虚拟磁盘由 Docker Desktop 管理。移动已使用的文件夹前，先从托盘完整停止旧路径的服务和容器。

### 从源码构建

仓库已附带可直接运行的 Windows x64 `栖.exe`。Windows 开发者也可在 PowerShell 执行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/windows/build.ps1`，使用系统 .NET Framework 编译器从源码重建，无需 Python 或额外 NuGet 包。

也可安装 .NET SDK 后运行 `dotnet build scripts/windows/Launcher.csproj -c Release`，会将 Windows 可执行文件复制到当前目录。该方式支持跨平台编译，但运行验收必须在 Windows 上进行。

`打开机器人.cmd`、`停止机器人.cmd` 保留为源码排错入口；脚本安装方式需要 Python Launcher，不作为普通用户的日常入口。

## 使用方式

完成首次配置后，在「会话与主动聊天」添加或读取好友、群列表，再为需要使用的会话勾选「允许读取并回复」。默认没有授权会话；启用主动联系也需要单独设置。

机器人 QQ 应使用独立账号，不能与管理 QQ 相同。模型可以选择保持安静；主动聊天的最长检查间隔不代表一定会发送消息。自主生活与其他工具按需开启。

管理界面位于 <http://127.0.0.1:8765/>。应用会自动打开并登录。**关闭浏览器不会停止机器人**，请使用菜单栏／托盘中的「停止机器人并退出」，或网页中的「关闭机器人」，等待退出完成。

同一电脑上的根目录原版、Windows 版和 macOS 版共用固定端口，使用时一次只启动一个版本。

## 项目结构

```text
Windows/
├── 栖.exe                   原生托盘应用（构建产物）
├── 打开机器人.cmd / 停止机器人.cmd   备用排错入口
├── bot/                    Python 机器人服务与业务逻辑
├── static/                 浏览器管理界面
├── initial/roleplay.json    首次启动的角色、世界书和生成预设
├── scripts/                Docker 接入、下载和维护脚本
├── docs/                   功能指南与设计说明
├── tests/                  离线测试
├── pyproject.toml          Python 依赖声明
└── uv.lock                 依赖锁文件
```

运行后生成的 `config/`、`data/`、`logs/`、`backups/`、`runtime/` 和 `.venv/` 均为当前安装的本地内容，已由仓库忽略规则排除。角色初始文件和源代码由同一个仓库管理。

## 打包发行

开发者构建原生应用后，可在本目录执行 `python3 scripts/package_desktop.py`（Windows 使用可用的 Python 3）。ZIP 生成在 `build/` 中，仅收录源码、初始角色、文档和原生启动器，排除配置、聊天数据、日志、虚拟机与虚拟环境。用户解压后直接双击应用图标。
