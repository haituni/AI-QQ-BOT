# 项目文档导航

日常启动：回到项目根目录，双击「栖.exe」，从系统托盘管理。[项目首页](../README.md)包含初次配置步骤。

- [桌面应用入口](guides/Windows应用入口.md)：图形安装、状态和退出。

- [运行与维护](guides/运行与维护说明.md)：启动、停止、备份、诊断和运行边界。
- [角色工坊](guides/角色工坊使用说明.md)：角色卡、人设、世界书、预设和试聊。
- [自主 QQ 生活](guides/自主QQ生活使用说明.md)：识图、表情库、QQ 互动、空间与自主时间。
- [模型工具](guides/工具菜单使用说明.md)：工具开关、额度和会话权限。
- [心情与情绪](guides/心情与情绪系统说明.md)：情绪、心动、关系感受及持续心境。
- [回复节奏](guides/回复节奏说明.md)：等待、分条回复与主动联系时间。

## 初始角色

初始角色、世界书和生成预设位于 `initial/roleplay.json`，首次启动自动加载。运行日志和数据由当前版本独立生成。
