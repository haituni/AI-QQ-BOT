# 自主 QQ 生活与识图

这是一个 QQ 账号的连续使用者。角色工坊当前启用的角色卡是这个账号统一的人格；全局性格、长期记忆、按人的磨合、关系感受和自身心境共同影响模型选择。启用自主生活时，会话中的旧角色卡绑定保留但不生效；关闭后可恢复原来的多角色模式。

在「模型工具」顶部设置自主生活，下面逐项启停工具、上传和管理表情。单个会话的授权、工具开关与工具允许列表继续有效。独立试聊和工具试运行不会发真实 QQ 消息，也不会改正式收藏。

## 能做什么

- 使用当前 `deepseek-flash` 按需看图：照片、截图文字、表情含义、多图关系。聊天先记录图片引用，模型选择看哪些；没有授权的会话不会保存引用或识图。单图6 MiB，默认每次4张，可配置1～6张，总原图上限24 MiB。语音、视频和文件内容暂不识别。
- 使用管理员上传的表情；根据偏好收藏聊天里收到的或搜索找到的图片；按含义挑选并发送。本地表情库先持久保存，再尝试同步 QQ 收藏，分别报告结果。QQ 收藏接口在某些版本不可用时，本地收藏仍可发送。
- 发文字、QQ 系统表情、表情包、引用回复；拍一拍/戳一戳（当前接入对应同一动作）；收到针对自己的拍一拍也交给模型决定是否回应；资料卡点赞、消息表情回应；撤回本账号有发送回执的消息。
- 看好友的近期 QQ 空间说说并点赞；发布原创文字/附图说说；选择所有人、好友、自己、指定好友可见或指定好友不可见。
- 只评论管理员已明确授权私聊的对象的说说。仅在群里见过一个人，不算已经获准评论其空间。
- 自主时间可以查看联系人元信息、回想一个已授权会话，再选择是否主动联系、逛空间、整理表情或休息。主动聊天只面向已授权会话；无需逐条命令或逐次确认。不能加删好友、进退群、踢人、改账号安全设置、读取本机任意文件或执行命令。

“可以做”不代表每次一定会做。失败回执会交回模型，模型不能凭空宣称成功。实现的是当前接入能够表达的这些能力；QQ App 的其他功能不会自动变成可调用工具。

## 心情与关系

按 QQ 号保存短期愉快、活力、紧张、亲近、心动和持续关系中的信任、依恋、安全感。同一个人在不同群聊和私聊中共享这些感受，场景只影响表达；不同人相互独立。角色卡与真实记忆决定如何理解事件，模型可保持安静、冷淡、拒绝、开心、矛盾或释然，不强制讨好。

短期情绪约3小时半衰期，亲近和个人心境约24小时，关系轴约90天；数值变化平滑、只有新的互动来源才更新关系，避免同一段经历反复加分。不会由数值自动宣布关系成立。私人事件原因、关系说明和个人时间计划按来源会话隔离；共享感受不共享私聊原文。

另外有账号自身的心境、活力、紧张、非隐私兴趣和内部想法，默认8小时自然恢复。它可以在自主时间延续自己的想法；聊天中的内部想法只在来源会话使用。角色核心不会被模型覆写，原有长期磨合机制继续工作。

## 默认配置

| 配置 | 初始值 |
| --- | --- |
| 识图与 QQ 生活、自主时间、QQ 空间 | 开启 |
| 评论已授权私聊对象 | 开启 |
| 自主活动时段 | 北京时间09:00～23:00 |
| 默认自主思考间隔 | 45分钟 |
| 每日 QQ 工具写操作尝试 | 40次 |
| 每日说说尝试 | 3次，可设为0禁止发布 |
| QQ 写操作冷却 | 30秒 |
| 说说间隔 | 120分钟 |
| 表情库容量 | 200张 |

模型可以选择5～1440分钟后的下次自主思考；管理员设置的活动时段、每日额度、操作冷却和全局暂停始终生效。相同起止时间表示全天，支持跨午夜。会话原有的主动聊天开关是另一种按会话检查机制；自主时间的联系由全局自主生活配置控制，仍要求会话授权和目标工具权限。

原有“每日模型调用上限”和“每日工具尝试上限”也生效。识图、空间发布的隐私检查是额外模型请求；搜索表情使用 DeepSeek 搜索接口。识图、表情搜索、本地表情检索和空间发布最多可用基础工具超时的三倍，整轮仍有180秒总时限。普通聊天最终文字回复沿用聊天节奏和会话主动限额；表情通过实际qq_send工具发送，受QQ工具写操作额度与冷却限制。

## 内容和回执

空间不能发聊天原文、聊天记录标记、QQ号、他人身份或隐私；允许根据经历写泛化原创感想。程序拦截原文/较长原文片段与数字身份信息，再由模型独立检查拟发布内容是否泄露隐私。检查不通过则不发，不自动改成公开。附图只使用管理员上传或搜索收藏的素材，聊天中收到的图片即使收藏也不用于空间。

写操作在请求前持久记录尝试，超时或连接中断记为“结果不明”，不会自动重试。重复的空间点赞、评论、发布及撤回会保守去重；发送、拍一拍和资料赞有短期去重。聊天发送与其他对外互动仍共享冷却；收藏及QQ收藏同步单独处理，不触发也不受聊天发送冷却影响，因此收藏后可以立即发送。收藏仍受每日额度与去重限制。已提交到 QQ 的请求不能通过暂停或撤权撤回。

图片引用最多保留7天、每会话100张；消息操作索引最多保留7天、每会话2000条。因此撤回或引用不能任意操作历史消息。收藏以图片字节保存在SQLite中，包含在常规备份里。清除聊天记忆会删除未收藏图片引用和该会话消息索引；已主动收藏的素材是独立表情库，需要在表情库单独删除。删除本地表情不删除已经同步到 QQ 客户端的收藏。

恢复备份会恢复表情、心境等资料，但不回滚已尝试的 QQ 操作记录和额度，避免重复发送。上游登录凭据只在内存里用于固定 QQ 空间接口，不交给模型、不写入表情记录或日志。

## 接入与验证

已通过200项离线测试、隔离控制台保存回读，以及一次真实 DeepSeek Flash 合成图片识图测试。正式新版已加载且原数据保留；QQ接入环境已启动，目前需要用机器人账号扫码登录，真实QQ/空间操作尚未端到端验证。真实空间浏览/点赞/评论依赖 QQ Web 协议、账号权限和登录态，模板或接口变化可能不可用；原生发布、收藏、消息互动也依赖 NapCat 版本。失败会在工具记录/自主活动回执显示，不伪造成功。

接口依据：[DeepSeek图像理解](https://api-docs.deepseek.com/zh-cn/guides/vision/)、[NapCat空间发布](https://github.com/NapNeko/NapCatQQ/blob/main/packages/napcat-onebot/action/extends/SendQzoneMsg.ts)、[NapCat表情收藏](https://github.com/NapNeko/NapCatQQ/blob/main/packages/napcat-onebot/action/extends/CustomFace.ts)、[QQ空间适配器作者的feeds3协议说明](https://github.com/Gu-Heping/onebot-qzone/blob/main/doc/feeds3-parser.md)。


## 最终回复格式恢复

工具阶段结束后会单独强调最终JSON决策。模型若额外包裹完整的JSON代码围栏，程序可直接读取；其他无法解析的输出最多补一次格式修正请求，该请求禁用工具，不会重做搜索、收藏或发送。修正仍无效则记录失败，不猜测成功。只有发生格式修正时增加一次模型调用。


## 表情语义检索与发送

模型先调用 `sticker_find(query)`，填情绪、意图或关键词。程序用本地中文 BGE-small-zh-v1.5 量化模型生成512维向量，对收藏描述进行余弦相似度检索，返回最多5个候选的ID、描述和分数。分数是相关度，不是概率；模型根据上下文、角色和偏好选择，必要时再识图。没有合适素材可以不发，或使用独立的 `sticker_search` 联网扩充收藏。

选好后模型调用 `qq_send({"sticker_id":"候选ID"})` 实际发送，其他字段可省略。最终JSON里的 `sticker_id` 不再发送图片。提示词只提供收藏数量，不注入整库描述或自动选图。

描述向量缓存在SQLite中；描述变更、素材删除、缓存损坏或模型版本改变后会重建。上传和收藏需填写画面、文字、情绪或适用场景描述，旧素材没有描述时会被排除，并在检索回执中报告数量。检索无相关候选时返回空列表，不回退为整库列表。

模型文件位于项目的 `runtime/models/bge-small-zh-v1.5/`，固定版本并校验SHA256。首次安装会下载约24MB权重和分词器；运行时检索完全在本机完成，不占用DeepSeek模型调用额度。缺少或损坏模型会明确报错，不改用字符串匹配。手动安装命令：

```sh
.venv/Scripts/python.exe scripts/setup_sticker_rag.py
# 下载需要代理时可加 --proxy http://127.0.0.1:7897
```

模型来源：[BAAI模型说明](https://huggingface.co/BAAI/bge-small-zh-v1.5)、[Xenova ONNX转换](https://huggingface.co/Xenova/bge-small-zh-v1.5)，MIT许可。本地推理禁用ONNX Runtime遥测。
