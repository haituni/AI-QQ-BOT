# AI 心情、情绪与回复节奏

每个「角色 + QQ」独立保存状态，没有所有人共用的心境。同一人在私聊和群聊中延续状态；不同人、不同角色互不影响。默认启用，从下一次有效聊天决策开始积累，不回放旧聊天自动补造情绪。

## 怎么表现

模型在同一次决策中结合人设、真实上下文、当前情绪，决定本轮态度、是否回复、气泡内容以及三个节奏：

- 收到最后一条消息到开始回复的目标等待时间，默认2～45秒，可在会话设置调整上限到120秒。模型和工具处理耗时包含在目标内。
- 同轮后续气泡的等待时间，每条1～12秒，受会话上限约束。
- 距离下次主动检查的分钟数，在该会话的最短～最长间隔内；到时仍可以选择不发。即使本轮不回复，也保存模型给出的下次检查时间。

不额外调用一次模型来判断心情或安排时间。模型漏填情绪或格式不合法时保留已有状态；缺少时间字段继续使用原有受限兜底，不付费重试。未开启主动联系时，情绪不能自行打开主动联系。

## 状态与变化

状态包含最多三个混合情绪标签，以及愉快、活力、紧张、亲近和持续心境。模型理解互动的意义，程序校验结构并限制变化：一般维度每轮最多0.25，亲近最多0.08，持续心境缓慢跟随愉快程度。这些是可调的工程参数，不是心理学量表。

短期维度向中性恢复的半衰期为3小时；亲近和心境为24小时。这里的亲近是当下放松亲切的感受，长期关系仍由角色设定、事实记忆和渐进磨合承接。长期没联系不会自动累积怨气。事件记录最多12条，作为近期情绪原因，不作为现实事实或用户关系已成立的证据；长期值得保留的用户原话继续交给原有记忆系统处理。

同一用户消息不会被重复检查反复推高情绪。新消息在模型返回前到达时，旧决策不写入情绪；等待过程中到达时取消未发气泡，结合新消息重新判断。已处理互动造成的情绪可延续到下一轮，已经成功发送的气泡不会重发。暂停、撤权、清除和断线继续拦截发送。

群聊普通决策参考最近真实发言者的个人状态，不生成全群共用情绪。群聊主动检查没有明确个人目标时不注入任何个人状态。群提示词和群会话管理视图不带入私聊中的情绪事件正文或计划原因；只延续这个人的情绪维度和有限标签。群聊多人同时发言时，这不是对每个人并行维护一次完整情绪评估。

## 心动值

新增独立的 `flutter` 心动值，范围0～100，默认0，按角色与QQ单独保存。它表示当下被这个人浪漫地打动的程度，区别于放松亲切的「亲近」；长期关系仍参考真实相处与记忆。模型在原有同一次决策中给出目标，程序限制每轮最多增减5点，重复消息不累加，并按短期情绪的3小时半衰期自然回落。普通赞美或要求加分不会机械触发；数值不自动确立恋爱或代表亲密互动的同意。

心动参与表达及三种回复节奏的判断，可以表现为期待、害羞或犹豫，不固定等同于回复更快。控制台和沙盒显示数值，正常聊天不主动报数。旧存储没有此字段时读取为0；模型漏填时保留当前心动值，仍然正常更新其余情绪。开关、重置、清除、备份、按人隔离和沙盒独立规则沿用情绪系统。

## 控制台

在「记忆与磨合」选择会话，查看「心情与回复节奏」：

- 当前用户、情绪标签和各维度、最近变化原因；群聊显示最近发言者。
- 最近一轮模型给出的气泡等待、主动检查间隔及简短原因。
- 正在等待的预计发送时间、已开启主动联系会话的下次检查时间。
- 情绪总开关，以及此角色对此QQ的单独重置。时间范围和回复节奏开关继续在会话设置调整。

计划是最近一次决策，不承诺发送：新消息、暂停、撤权、断线或关闭主动联系都可能取消。关闭情绪不清除已有状态，但不注入或写入新情绪；关闭回复节奏时仍使用原来的即时首条和0.8秒气泡间隔。

重置不删除事实记忆、聊天或磨合。为防止跨会话的旧回复恢复已重置状态，开关和重置会使当前待处理决策失效。清除某会话的全部记忆时，也清除此会话涉及QQ的派生情绪；同QQ的其他会话中形成的派生情绪也会重置。备份恢复包含情绪及总开关，旧备份无此数据时从中性重新开始。

## 独立试聊

角色工坊沙盒在浏览器内单独延续情绪，不读取或写入正式QQ情绪。切换试聊角色、人设、预设或重置试聊后重新开始。沙盒显示时间计划，不实际等待或发送QQ。真实上下文预览可以查看该真实会话实际使用的情绪，仅预览不写入状态。

## 连续人格与自主生活

增加按QQ持续的信任、依恋、关系安全感，以及账号自身的心境、兴趣和自主时间。启用自主生活后，所有会话统一使用工坊当前角色；同一个人的感受跨场景延续，私人原因不跨场景。模型根据角色卡、记忆、当前性格决定情绪表达，可以拒绝或沉默，不强制积极。详见[自主QQ生活使用说明](自主QQ生活使用说明.md)。
