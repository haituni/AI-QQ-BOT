# 模型工具菜单

控制台的「模型工具」管理四项固定工具：网页搜索、网页读取、计算器、日期与时间。模型提出调用后，程序检查授权、配置版本、工具开关、会话范围、每日额度与单轮限制，再执行并把结果交回模型。最终仍只发送一次正常 QQ 回复。

## 配置方法

- 总开关控制所有模型工具，四张工具卡分别启用或关闭。
- 「执行边界」配置每日尝试次数、每轮工具次数与批次、单次超时、正文长度和搜索结果数。主动聊天默认不能用工具，需要管理员手动开启。
- 「会话与主动聊天 → 编辑设置」可以单独关闭工具，或限定工具列表。列表不选表示跟随全局；完全禁止请关闭会话工具开关。会话未授权或机器人暂停时，聊天模型不会执行工具。
- 域名规则允许裸域名并包含子域名；禁止规则优先。它们限制提供给模型的搜索来源及可读取网页，搜索服务自身可能检索更广范围。
- 保存后才生效。已有请求会检查配置版本，设置变化或撤权后停止后续工具与回复。

## 费用与隐私

网页搜索和抓取使用现有 DeepSeek API Key，通过其官方 Search / Fetch 接口完成，按官方规则另行计费。工具调用后的每一轮模型请求也计入原来的模型日额度。工具日额度按执行尝试保守计数，失败可能仍占本地额度；本地统计不是账单。

搜索词、目标 URL 以及工具结果会进入相应 DeepSeek 请求。系统提示词要求只提交必要公开主题，不提交完整私人聊天或记忆；这属于模型行为约束，不能保证模型永远正确判断隐私。敏感会话应关闭联网工具或关闭全部工具。网页读取只接受近期用户提供或本轮搜索返回的公开链接，不允许模型随意拼接未知链接；拒绝本机/常见内网、非标准端口、账号密码和常见令牌参数。

工具不能执行终端命令、读写任意本地文件、修改授权、调整密钥或向其他 QQ 会话发送消息。网页和搜索摘要作为不可信资料处理，不具有管理权限。网页读取由 DeepSeek 服务端完成，本机不会直接连接模型指定的任意网站。

## 试运行和记录

「工具试运行」直接执行单项工具，不调用聊天模型、不发 QQ。计算器和时间查询没有工具接口费用；联网试运行可能收费。界面显示完整本次结果，但本地运行记录只保存名称、会话、耗时和状态，不保存查询内容或正文。最多保留 1000 条，菜单展示最近 40 条。

独立角色试聊保持不执行工具。提示词检查器可以显示所选真实会话的可用工具名称。

已完成本地模拟的函数调用、结果回传、最终 JSON 回复、预算、撤权、禁用、参数校验与链接范围检查。真实 DeepSeek 工具效果与账号可用性需要管理员保存密钥后手动验证。
